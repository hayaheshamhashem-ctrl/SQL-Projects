# SQL Projects

A collection of SQL projects focused on data analysis, business insights, and financial analysis.

## Project

### Financial Analysis Using SQL

Analysis of SEC financial statement data using PostgreSQL to explore company filings, industries, geographic distribution, filing types, and financial performance.

**Dataset:** SEC Financial Statement Data Sets  
**Database:** PostgreSQL  
**Tools:** SQL, pgAdmin 4
## Data Source

This project uses the U.S. Securities and Exchange Commission (SEC) Financial Statement Data Sets, which provide structured financial data derived from company filings submitted to the SEC. The dataset was downloaded from the SEC's official website and analyzed using PostgreSQL.
